Rustで予約語を識別子として使う(Raw Identifier)

投稿日: 2026年08月03日 22:47:58

更新日: 2026年08月03日 22:47:58

typeとかmatchみたいな予約語を変数名として使いたい時がある．
例えば，ELFのパーサを書いていて，ElfHeader構造体にe_typeとしてtypeを持たせたい時など．

そんな時はr#を先頭に付与すると，予約語が使えるようになる．

struct ElfHeader {
    pub ident: EIdent, 
    pub r#type: u16, 
    pub machine: u16, 
    ...
}

みたいな感じ．
